        Research directions, mapped to specs

        A → spec 034Execution-aligned, uncertainty-aware decision policy

        Predict the distribution of a tradable return; trade only when expected gain beats costs, risk and uncertainty. Maximize μ′w − (λ/2)w′Σw − cost(w − wprev) with a no-trade region. Start with a calibrated baseline and a small quantile tree, not a transformer.

        B → spec 036One narrow point-in-time cross-sectional hypothesis

        A reason returns are predictable after costs, e.g. relative trend/reversal conditional on volatility and liquidity, on a broad predefined panel. Residualize market and sector. Split by global date. Costly external data only after this works.

        C → spec 032Covariance-aware risk with turnover-aware execution

        Shrinkage covariance plus sector/factor limits vs the current overlap rule, with a no-trade band. Must improve a preregistered net objective and survive doubled costs and correlation shocks.

        D → Phase 4, P4-dReplayable, auditable research-to-paper pipeline

        Immutable snapshots → causal features → run store → approved model/policy → targets → order intents → fill/cash/risk journal → read-only UI. Same decision code for history and paper via adapters.
