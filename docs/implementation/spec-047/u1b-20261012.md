## T009 — V1 and Rule 12
`npx vitest run --config mutation/run_047_u1b.config.ts` uses `mutation/mutate.ts` (T005 helper, read-only).
It runs only the view test (`mutation/run_047_u1b.view.config.ts`) and restores the view byte-for-byte:

| Mutant | Edit | Outcome |
|---|---|---|
| control | unmutated view | green |
| V1 (T008) | commission ← `trade_log.length * (2 * commission_per_trade)` | killed (`047 U1B commission`) |
| V1b | commission ← `commission_total + slippage_total` | killed (`047 U1B commission`) |
| V1c | the sum shown in the TOTAL NET P&L subtitle, one decimal (outside the card) | killed (`047 U1B no sum`) |
| V2 | slippage ← `slippage_bps` | killed (`047 U1B slippage`) |
| V3 | label loses "modeled" | killed (`047 U1B label modeled`) |

**Driver red proof.** With the commission and no-sum assertions temporarily weakened in the view test, V1 and V1b
reported `survived` and the driver failed (2 failed, 3 passed). With the no-sum assertion removed, V1c
reported `survived` (1 failed, 5 passed). Each time the test was restored, `cmp`-clean against its saved copy.

**Known risk (T005 helper, read-only here).** `runMutant` restores the view in a `finally` block. If the driver is
killed during its blocking `spawnSync` (Ctrl-C, OOM), the view stays mutated. Check with `git status` after an
interrupted run, and restore `BacktestTearsheetView.tsx` before building. U1b is the first driver that mutates a
`src/` file.

The driver is not in the default suite (`vitest.config.ts` includes `mutation/*.test.ts`; the driver is
`*.mutants.ts`), because its mutants edit the view in place and would race the view test.
