## Mechanism and boundaries

- Q124 rebuilds the matrix identity from a verified ledger snapshot, immutable family
  declaration and bound return sidecars. It echoes no artifact-supplied matrix hash.
  Missing policy, drift or an ineligible selected candidate produces unknown currentness.
  It computes no DSR, HAC or PBO. A corrupt/incomplete backfill cannot supply a current hash.
- Q124 also accepts an explicit `holdout_spend` audit record bound to a completed selected
  candidate's trial/config hash and family. Existing `holdout` starts retain their format.
  Both forms share the one-spend guard; the new event adds no production writer or
  holdout-opening permission. Existing holdout evidence stays spent.
- T063 reads only the latest index row, checks the exact confined path and SHA-256,
  validates recorded schema/operands/provenance and delegates currentness to the generator.
  Recorded lifetime/family DSR input counts must agree with the declared history count;
  a self-hashed artifact with inconsistent counts is still rejected.
  A malformed last record never falls back to an earlier pass. Unknown/stale reasons are
  retained. Passed, failed and stale responses carry a repository-relative evidence path.
- T064 states inclusive DSR >= 0.95 and HAC t-statistic >= 3.0. Valid S=16 PBO is
  mandatory diagnostic evidence, with no invented PBO cutoff. The reader accepts the
  evaluator's one-fold boundary and requires positive purge/embargo and recorded realistic costs.
- Gate 3 does not change Gates 1/2/4/5 or overall capital acceptance.
