EEM, SHY, IEF, TLT, LQD, HYG, TIP, GLD, VNQ, DBC, UUP.

Method: two case-sensitive searches over every file under `scripts/`, `reports/` and `docs/trials/`
except `__pycache__/` (120 files; `reports/web/node_modules` absent):

1. Whole-word match: `grep -rlwE 'SPY|QQQ|…|UUP'`.
2. Any occurrence not inside a longer upper-case token, so `SPY_close` or `"SPY"` would also match:
   `grep -rnoE '(^|[^A-Z])(SPY|…|UUP)([^A-Z]|$)'`.

Result: both searches hit exactly one file, `docs/trials/families/058-edge.json`. That file is the
058 family declaration (T006: Camden's one command after the T005 code PR #126 merged; recorded
`declared_at_utc` 2026-10-09), whose `universe` field lists
the §4 tickers by design. It is the preregistration, not a prior screen, so spec 058 D-1(b)
("disjoint from every prior screen") holds. No file in `scripts/` or `reports/` names a §4 ticker,
and no ledger row in `trials.jsonl` names one.

  beside the declaration.

  (`_` is a word character for `grep -w`), which is why search 2 exists.
